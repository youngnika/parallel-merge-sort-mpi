# Parallel Merge Sort with MPI

Реализация параллельной сортировки слиянием на C/MPI и экспериментальное исследование на суперкомпьютере «Ломоносов-2».

## Алгоритм

Процесс с рангом 0 формирует массив. `MPI_Scatterv` распределяет элементы между процессами.
Каждый процесс выполняет последовательную сортировку слиянием своей части.
Затем отсортированные части объединяются по бинарной схеме через `MPI_Send` / `MPI_Recv`.

## Сборка

```bash
mpicc -O2 -std=c99 -Wall -Wextra src/merge_sort_mpi.c -o merge_sort_mpi
mpicc -O2 -std=c99 -Wall -Wextra src/merge_sort_mpi_profile.c -o merge_sort_mpi_profile
```

## Пример запуска

```bash
mpirun -np 8 ./merge_sort_mpi 10000000
```

На «Ломоносове-2» использовались OpenMPI 4.1.8, Slurm и параметры сетевого интерфейса,
указанные в `scripts/*.sh`. Скрипты предназначены для этой среды и могут потребовать
изменения путей, MPI-модулей и параметров запуска на другом кластере.
Рабочую директорию можно переопределить переменной `MERGE_SORT_DIR`.

## Результаты

Исследованы сильная и слабая масштабируемость для 1–32 MPI-процессов.
Максимальное измеренное ускорение: **5,319×** при **8 процессах**
для массива из **10 000 000** элементов. Итоговые результаты в `results/summary.csv`;
сырые измерения и профилирование — в `results/`.

## Структура

- `src/` — исходники MPI, профилирования и исследования локальности.
- `scripts/` — сценарии измерений и обработки данных.
- `results/` — CSV-файлы экспериментов.
- `docs/algowiki/` — текст статьи в MediaWiki-разметке.
- `docs/figures/` — иллюстрации.

Не включены скомпилированные бинарники, журналы заданий и подробная трасса
`memory_trace.csv`. Скрипты сохраняют конфигурацию кластера для воспроизводимости.
